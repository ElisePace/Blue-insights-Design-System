Inline notice banner. Tones map to semantic colours; `transparency` is the beige "How this was generated" AI explainer.

```jsx
<Alert tone="warning" title="Review before sharing — 1 sensitive figure">12%</Alert>
<Alert tone="transparency" title="How this was generated.">The agent joined three sources…</Alert>
```

Tones: `warning`, `error`, `info`, `success`, `transparency`.
