Status and label pill. Always pairs colour with a word (and optionally a dot) — never colour alone.

```jsx
<Badge tone="success" dot>Confirmed</Badge>
<Badge tone="warning" dot>Needs review</Badge>
<Badge tone="error" dot>Blocked</Badge>
<Badge tone="error" uppercase>Restricted</Badge>
```

Tones: `neutral`, `primary`, `success`, `warning`, `error`, `info`. `dot` adds a leading status dot; `uppercase` tracks + capitalises for terse labels.
